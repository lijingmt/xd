# 百工复兴设计与验证说明

## 目标

本次改造重新打通采矿、采药、锻造、炼丹、裁缝和制甲，让旧配方继续有效，
同时给 70 级之后的角色提供长期制造目标。设计坚持三条边界：旧人物无需迁档、
制作不能复制物品、付费等级不直接提高制造属性上限。

## 玩家入口

- 在“我的技能”打开“百工坊”。即使尚未学习任何手艺，也能看到入口。
- 六门基础手艺可以全部学习，每门仍收取 10 金，不再受旧版“最多两门”限制。
- 采矿、采药默认自动收入材料囊；制作会合并计算材料囊和包袱中的材料。
- 装备类支持每次 1、5、10 件，服务端上限为 20 件；炼丹每炉最多 100 颗。
- 任一制造手艺达到 210 熟练度后，可选择一门大师专精。

## 大师专精

| 规则 | 数值 |
|---|---:|
| 首次选择 | 免费 |
| 切换冷却 | 7 天 |
| 再次切换费用 | 100 金 |
| 高阶制作起点 | 人物 80 级 |
| 高阶间隔 | 每 20 级一阶 |
| 高阶批量上限 | 5 件 |
| 品质幸运加成 | 5～20，封顶 20 |
| 匠心保底 | 动态品质连续 30 次未出高品质后触发 |

锻造、裁缝和制甲大师可以把已经学会的 65 级以上配方升阶制造，目标等级不能
超过人物等级。升阶只复用装备种类，不复制 Boss 独有效果。炼丹大师以百颗批量
炼制和补给配方为主要优势，不生成装备。

## 历史兼容

- `vice_skills` 仍是熟练度唯一权威数据，旧等级、进度和上限原样读取。
- `/duanzao/*`、`/liandan/*`、`/caifeng/*`、`/zhijia/*` 仍是配方唯一权威数据。
- 新字段只写入 `/artisan/*`，没有离线批量迁档，也不覆盖旧背包和装备。
- 旧公式留下的较大熟练度进度会折算到新公式，不会在首次制造时被清零。
- 锻造 125～140 号“通用武器”历史分类已经接回学习、查看和制作链。
- 炼丹 94、95 号补给配方从错误的 `attri_base` 迁入 `attri_supply`；旧已学标记
  在人物初始化时安全转移。

## 材料与制作事务

制作流程按下列顺序串行执行：

1. 校验技能、配方、熟练度、人物等级、批量上限和材料数量。
2. 创建产物并确认产物确实进入当前人物包袱。
3. 从材料囊和包袱合并扣除材料，记录完整回滚快照。
4. 推进熟练度、更新匠心进度并原子保存人物。
5. 保存失败时删除新产物，恢复材料、熟练度、匠心和强化材料选择。

所有 `artisan*` 和 `viceskill_*` 写命令都归入 HTTP 核心串行队列，避免同一人物
的并发点击破坏因果顺序。材料囊只接受材料目录中的可堆叠原料；取出时会再次
校验模板路径，损坏或伪造的存档路径不会被加载。

## 十轮审查记录

| 轮次 | 范围 | 结果 |
|---:|---|---|
| 1 | Pike 语法、宏与 include 链 | 移除低层读书模块对高层宏的越层引用，全部文件可编译 |
| 2 | 旧人物、旧配方和旧熟练度 | 旧字段保留，缺失分类按访问补齐，旧进度安全折算 |
| 3 | 配方目录完整性 | 锻造 140、炼丹 95、裁缝 87、制甲 87，共 409 张逐项验证 |
| 4 | 材料扣除与失败回滚 | 材料囊和包袱混合扣料；存档失败路径保留完整回滚状态 |
| 5 | 批量和输入边界 | 装备 20、炼丹 100、高阶 5；零数、负数、超限和伪造配方均拒绝 |
| 6 | 大师成长与平衡 | 单专精、210 门槛、7 天切换、金币回收、幸运封顶和 30 次保底 |
| 7 | 并发与重复点击 | 新旧百工写命令保持核心串行，不引入额外线程锁或账号死锁 |
| 8 | 手机/浏览器操作闭环 | 技能页、百工坊、材料囊、分类返回和高阶制作均有明确返回路径 |
| 9 | TestUnit 隔离 | 测试人物前后清档；随机命中按战果一致性判定，连续重启不产生残档或概率误报 |
| 10 | 重启、部署和运行日志 | 无新增配置；守护与命令随现有代码镜像复制，重启后检查错误日志 |

- 基础手艺真实学习、非法技能名和金币扣除；

- HTTP 核心串行接线与采集入口。
