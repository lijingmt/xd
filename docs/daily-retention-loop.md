# 每日签到与每日修行系统

## 玩家循环

`daily` 命令统一展示每日签到、六项真实行为目标和四档活跃宝箱。Vue
常用功能区显示“每日修行”；有签到或宝箱可领时显示“每日可领”。旧界面可从
任务列表进入。

每日目标不是点击即完成：

| 目标 | 要求 | 活跃度 | 服务端事件 |
| --- | ---: | ---: | --- |
| 每日签到 | 1次 | 10 | `claim_signin()` |
| 同阶除魔 | 击败自身等级前后10级内怪物5只 | 25 | `TASKD->if_in_killTask()` |
| 勤修术法 | 成功施放技能5次 | 20 | `skills_level_check()` |
| 完成历练 | 提交普通任务或每级职业历练1次 | 25 | `clearTask()` / `claim_growth_task()` |
| 万灵同行 | 服务端真实触发灵宠协战3次 | 20 | `perform_pet_combat_assist()` |
| 采集天地 | 成功采药或采矿3次 | 20 | `viceskill_gather` / `viceskill_dig` |

基础战斗、技能、任务与签到可以达到80点；100点最终宝箱需要再完成灵宠或
采集中的一种，给长期系统留出自然引导，但不会把全部奖励绑在组队、PVP或VIP上。

## 奖励与公平边界

- 签到采用友好的七日累计轮次：第1至3天一倍，第4至6天两倍，第7天三倍；
  漏签不会清空累计轮次，每个自然日只能领取一次。
- 活跃宝箱为20、50、80、100四档，只发人物经验和金币，不发共享玉石、
  共享仓库物品或PVP属性。
- 经验继续经过既有统一经验发放函数、界面经验规则与有效等级上限；VIP不会
  增加签到次数、任务活跃度或宝箱领取次数，也不额外放大日常奖励。
- 多人物账号按物理人物档案独立保存进度。这样每个职业都能成长，同时不会把
  可重复奖励导入账号共享资产。
- 同阶除魔拒绝低于人物10级以上或高于人物10级以上的怪物，避免反复击杀
  无风险低级怪刷活跃度。

## 存档与并发

状态保存在人物档案的 `/plus/daily_goal`，包含版本、当前自然日、累计签到数、
最后签到日、当日进度和已领宝箱。跨日读取 `/api/status` 时只构造虚拟空状态，
不在轮询线程写档；首次真实操作才重置昨日进度。签到和领奖命令被列为HTTP
核心命令，并且先写领取凭据再发奖，重复请求不会重复获利。成功领奖后立即调用
人物原子存档，正常进度仍随既有周期存档。

## 维护清单

- 新增目标必须有一个真实、成功后才触发的服务端事件，不能相信客户端上报。
- 新增共享或稀缺奖励前，必须重新审计多人物账号、并发请求和回档复制风险。
- 状态轮询函数必须保持只读，不能在 `/api/status` 的高频路径执行存档。
- 修改目标、阈值或奖励后，同步更新 `test_unit/test_daily_goal_system.pike`、
  Vue构建契约和游戏介绍PDF。
