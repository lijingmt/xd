# 仙道装备图片与等级光效

本轮装备图使用内置图像生成工具原创生成，没有使用外部游戏、影视或素材
网站的参考图。原始图集保存在
`images/equipment/fallback/original-atlas.png`，十六类透明装备图保存在
`images/equipment/fallback/`。

生成目标是严格的 4×4 仙侠装备图集，依次包含双手武器、单手剑、匕首、
法杖、头冠、仙袍、护腕、手甲、腿甲、靴子、戒指、项链、手镯、披风、
挂件和法宝；要求原创手绘仙侠风格、64 像素下轮廓清楚、无文字、无标志、
无水印、无现有商业游戏风格引用。

现有 386 类基础装备优先使用自己的图片。缺图模型由
`scripts/generate_equipment_image_variants.sh` 按装备部位选择原创底图，
生成独立文件名并同步到 `images/` 与 `web/images/`。脚本只补缺失文件，
不会覆盖已有美术。

Vue 装备面板同时表达两个维度：

- 稀缺度决定边框主色与辉光颜色；
- 装备需求等级决定外圈层数、光效距离与高阶呼吸效果。

人物头像另按 1、30、60、90、120、160、200、250 八个等级段增强外圈，
仅改变显示，不修改人物或装备数值。
