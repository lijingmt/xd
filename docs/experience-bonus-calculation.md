# 打怪经验加成计算

打怪经验统一使用以下顺序，单人和组队共用同一入口：

1. 根据怪物等级、玩家等级和队伍人数得到基础经验。
2. 叠加 `te_exp` 与 `attri_exp` 药品百分比。
3. 按历史活动规则额外增加对应倍数；配置 `2` 表示额外增加 2 份，与修复前玩家收益一致。
4. 将捐赠经验倍数作用于以上完整总额。
5. 最后计算 Vue/HTTP 新界面加成并一次性入账。

因此，100 点基础经验、50% 药品、活动额外 2 倍、2 倍捐赠的结果为：

```text
(100 + 50) × (1 + 2) × 2 = 900
```

捐赠档位是作用于药品和活动后完整经验的最终总倍数，而不是只在基础经验上追加：200/400/600/800/
1000/1200/1400/1600/3200/6400/12800 元分别对应 2/3/4/5/6/8/10/20/30/40/50 倍，
超过最高档仍为 50 倍。

核心计算位于 `lowlib/mudlib/inherit/feature/level.pike`，NPC 单人和组队奖励统一通过
`grant_kill_experience()` 发放。回归覆盖位于 `test_unit/test_experience_bonus.pike`。

## 新手追赶经验药

追赶药只用于缩短新角色前期追级时间，不改变70级后的成长平衡：

| 药品 | 打怪总经验 | 持续时间 | 获取规则 |
| --- | ---: | ---: | --- |
| 二倍追光露 | 2倍（`te_exp +100%`） | 30分钟 | 1～19级在新手补给商店手动免费领取一次；20～69级3碎玉 |
| 三倍曜光露 | 3倍（`te_exp +200%`） | 30分钟 | 20～69级8碎玉 |
| 五倍星河露 | 5倍（`te_exp +400%`） | 30分钟 | 20～69级20碎玉 |

新人物不会自动收到追赶药，需由玩家在新手补给商店主动领取。三档价格和物品由服务端固定，购买时支持玉石自动兑换。达到70级后，购买入口和服用守护进程都会拒绝操作，物品不会被误扣；原有分神丹、化神丹、幻神丹等普通经验药不受此限级规则影响。所有追赶药均不可丢弃、交易、转赠或存仓，同类 `te_exp` 效果不叠加，后服用的药效覆盖原效果。

相关回归覆盖位于 `test_unit/test_catchup_exp_potion.pike`。
