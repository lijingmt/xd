# 打怪经验加成计算

打怪经验统一使用以下顺序，单人和组队共用同一入口：

1. 根据怪物等级、玩家等级和队伍人数得到基础经验。
2. 叠加 `te_exp` 与 `attri_exp` 药品百分比。
3. 乘当前活动倍数。
4. 将捐赠经验倍数作用于以上完整总额。
5. 最后计算 Vue/HTTP 新界面加成并一次性入账。

因此，100 点基础经验、50% 药品、2 倍活动、2 倍捐赠的结果为：

```text
(100 + 50) × 2 × 2 = 600
```

捐赠档位是最终总倍数，而不是“在基础经验上额外增加 N 份”：200/400/600/800/
1000/1200/1400/1600/3200/6400/12800 元分别对应 2/3/4/5/6/8/10/20/30/40/50 倍，
超过最高档仍为 50 倍。

核心计算位于 `lowlib/mudlib/inherit/feature/level.pike`，NPC 单人和组队奖励统一通过
`grant_kill_experience()` 发放。回归覆盖位于 `test_unit/test_experience_bonus.pike`。
