# 新月幻境 AAA 品质路线图

本文把“AAA”定义为可度量的品质门槛，而不是功能数量。S1 必须先稳定、可完成、可理解，再增加内容。

## 当前基线

- 81 章、9 卷、3 条命途、9 场卷主战、9 组剧情信物、九卷支线、隐藏职业和赛季排行榜已经存在。
- 完整 Pike TestUnit、真实人物进入游戏冒烟和 3 Worker active 环境已经建立。
- 主要差距是线上压力、章节耗时和经济平衡仍缺少一周以上真实数据；普通战斗已建立第一轮差异化机制，但仍需依据真实应对率继续打磨。

## P0：可上线与可恢复

验收门槛：

1. 完整重启 TestUnit 必须为零失败。
2. 3、5、8 Worker 模式分别完成启停、重启、故障回退和存档验证。
3. 任意章节断线、重启、跨 Worker、背包满或首领刚被击杀后，都能继续原章节且不能重复领奖。
4. 玩家任务页必须提供可复制的诊断码；恢复操作不得重置进度、跳章或伪造击杀。
5. 50 名玩家连续 24 小时压测期间，P95 操作延迟低于 800ms，存档失败为零，Worker fallback 为零。

## P1：关卡与战斗表现

验收门槛：

1. 81 章均有明确的关卡节奏、三幕战斗反馈和唯一剧情图。
2. “下一步”一次点击即可完成安全传送，并自动进入阅读、限章挂机或真实首领选择页。
3. 6 类普通怪和 9 名卷主必须拥有不同预警、应对、失败反馈和结算提示；不能只改变名字与血量。
4. 所有持续伤害、护盾、治疗、召唤和宠物灵技都有施放、心跳与结算反馈。
5. 12 个普通职业分别完成永恒/S1 全八档真实战斗矩阵；隐藏职业至少覆盖基础、问道、凝真与破境。

## P2：内容厚度与长期循环

验收门槛：

1. 主线、支线、命途和隐藏职业之间不能出现循环前置或提前剧透终章首领。
2. 每卷至少包含探索、普通战斗、剧情事件、信物追寻和机制首领五种节奏。
3. 套装、宠物、契印和难度必须形成至少三种可用构筑；不存在唯一正确答案。
4. 每周通过掉落、锻造、交易和消耗数据复核通胀；不得凭主观直接改核心公式。
5. 管理员关闭赛季后的自动结算需覆盖背包满、共享仓库、绑定物品、离线人物和重复登录；进行中不得被日期误关闭。

## P3：UI、演出与设备覆盖

验收门槛：

1. PC、iPhone、Android、iPad 四类视口都能显示完整任务图、主操作和返回按钮。
2. Vue 真实模板 SSR、HTTP 资源探测、旧 JSP 书签和旧命令必须同时通过。
3. 重要剧情拥有开场、过关和卷末视觉演出；图片自适应且不遮挡操作。
4. 常用商店、药品、仓库、赠送和装备流程均支持合理批量操作。
5. 新玩家在没有管理员解释的情况下，可以从创建人物走到第一个卷主。

## P4：生产验证与发布门禁

正式合并前必须同时满足：

- 自动化全流程覆盖全部职业、81 章、三命途、九卷支线和隐藏职业。
- 205 或试运行服连续一周无 P0/P1 存档、登录、战斗和 Worker 故障。
- 真实玩家章节流失点、死亡率、信物保底、套装产出和经济净流量已形成周报。
- 发布脚本能够安全停流、证明全部存档、启动指定 Worker 数并验证 active。
- 回滚演练成功，且回滚不会复制装备、回退已领取奖励或丢失人物状态。

## 本轮已执行

- 普通章节增加九幕战斗身份和起势、转折、收束三段反馈，不改变核心数值。
- “下一步”到达目标后自动阅读剧情或启动限章挂机；首领仍从房间真实对象中确认后挑战。
- 新增玩家可见的任务自检与诊断码，恢复入口只继续当前合法步骤。
- S1 改为管理员显式关闭，进行中不再按日期到期；关闭后保留跨 Worker 结算窗口，且不依赖重启。
- S1 难度改为每档在当前最高难度完成 9 个新章回，任务击杀记录最低实战档位，禁止低难打完后临时切高领奖。
- 六类普通怪增加低频轻量应对，九名卷主保留独立机制；普通怪失误不会直接致死，也不改动 PVP、永恒服或核心伤害公式。
- 章节领取日志增加章号、墙钟耗时和真实战斗难度；`scripts/audit_illusion_chapter_metrics.sh` 只输出聚合数据，用来定位卡章和保底过高，而不暴露玩家标识。
- 对上述行为补充 TestUnit，并继续使用完整重启和真实人物冒烟作为发布门禁。
