# 仙道幻境区：新月幻境·S1

## 定位

`S1` 是首期永久编号，玩家界面显示“新月幻境·S1”。S1 不设自然到期日，
管理员未显式关闭时会持续开放。
玩家按注册账号免费激活本期资格；资格只对当前永久编号生效，`S1` 资格不能解锁
`S2`。激活后，每个幻境人物栏位都需要单独扩充：100 碎玉购买 1 个，500 碎玉
购买 5 个。没有“第一个人物免费”或无限人物开关；已有的早期 S1 人物只做兼容
保留，不追扣、不删除。没有激活也不影响永恒服和旧登录方式。

S1 当前永久资格价格为 0 碎玉，即免费激活。仍保留幂等资格、凭据和审计流程，
避免重复请求生成不一致的账号状态。

幻境人物始终使用一份普通人物 `.o` 档案。期满回归只改变账号人物索引中的
世界状态，不复制人物、背包、装备或仓库数据。

## S1 内容

- S1 主线名为《新月长生劫》，是原创九卷八十一章长篇故事。玩家以“无籍客”身份
  从逐出师门开始，走过南瞻、西牛、北俱、东胜四洲残境，逐步查明长生方以姓名、
  记忆与寿数为代价的真相。主要人物晏孤峤、骆燃川、商清晏、祝无晷及其关系线均
  为本项目原创设定，不引用现有动漫、游戏或小说角色。
- 43 个静态房间属于同一逻辑幻境，但不挤在一个进程：剧情和公共猎场分为
  `hub`、`silver`、`ruins`、`depths`、`hunt_a`、`hunt_b`、`hunt_c`
  七个亲和组。每个具体房间仍只有一个 Worker owner，同房玩家一定能相遇；七组
  由全部 Worker 共享承载，不预留“幻境专用 Worker”。
- 八十一章必须顺序完成；满足逐章等级、击杀、首领、探索与剧情条件即可立即推进，
  活跃日只用于运营分析与排行榜，不作为章节门槛。25 个关键节点必须在指定剧情
  房间阅读残响或击败指定剧情首领，不能只点“完成”跳过。第 9、18、27、36、45、
  54、63、72、81 章合计发放
  本职业 10 件新月底版套装。
- 章回等级按第 1 至 69 章逐级推进，69 至 81 章保持 69 级终局门槛。领取已完成章节
  会用固定剧情经验补足到下一章最低等级，已有打怪经验不会丢失，也不会改动永恒服
  的经验、伤害或数值公式。六档公共猎场分别从 1、10、20、30、40、50 级起步；
  九名剧情首领严格等于所在章回等级，不再让 1 级人物面对 8 级首怪。
- 九卷各使用一张原创 3×3 分镜母图，并导出 81 张互不重复的独立章节图；Vue 和旧
  JSP 的开章与过关回响共用对应章节图。配置只接受固定静态目录和准确章节编号，
  非法路径或缺图会让幻境安全关闭。
- 每章只突出一个“下一步”：自动直达目标地图，随后引导阅读残响、探索、启动自动
  打怪或领取本章。每次击杀即时显示本章进度，目标完成后直接出现领取按钮；领取后
  直接进入下一章，不要求玩家反复寻找地图、怪物或菜单。若下一步不再是普通狩猎，
  章节助手会自动暂停挂机，避免提前刷掉后续目标；下一步仍是狩猎时则保持运行。
  传送成功页面必须重新读取最新进度：普通狩猎直接显示“挂机至本章狩猎完成”，
  首领目标直接显示“挑战本章首领”，两种页面均显示“返回游戏”。不得退化为只有
  地点提示而没有可执行任务按钮的中间页。
- 第二十三章前选择一条本期不可更改的路线：
  - 寻星：寻找水镜月印、隐月星核、归真月印；
  - 破阵：分别击败断桥镇星使、月庭巡将、归真月主；
  - 同心：完成配置要求的同队击杀。
- 章节奖励逐人物领取、账号绑定、重复请求幂等。领取落盘失败会同时撤销装备
  和领取状态。

## 人物栏位与隐藏职业额度

- 登记 S1 赛季资格本身不收费，但每创建一个 S1 人物都要占用一个已付费栏位：
  100 碎玉购买 1 格，或 500 碎玉购买 5 格。每一期赛季分别计算人物栏位，
  不能用 S1 的栏位免费创建未来 S2 人物。
- 同一注册账号默认最多创建 3 个无相、2 个太极。玩家选择对应职业时，人物中心
  必须显示“已创建数量 / 当前已购上限 / 最高上限 10 个”。额度用满后可购买下一格：
  第一次 5000 碎玉，第二次 10000 碎玉，此后每格增加 5000 碎玉，单职业最多
  提升至 10 个。购买额度永久属于该注册账号和该职业，不因赛季结算清空，也不退款。
- 隐藏职业额度只放宽“可以创建几个”，不会绕过职业自身解锁条件。创建 S1 人物时，
  除隐藏职业额度外仍需另有一个 100 碎玉的本期人物栏位。
- 人物中心可将非默认、已离线的人物移入管理员可恢复的安全归档。操作必须
  重新输入注册账号密码与完整人物 ID；跨 Worker 在线状态不能证明时一律拒绝。
  归档后释放活动人物栏位，但不退还已购买的 S1 栏位或隐藏职业额度。

## 世界隔离

进行中的幻境人物不能接入永恒服的账号共享仓库、共享宠物和拍卖行。跨世界
的可见、战斗、组队、聊天、邮件、赠送和交易继续由逻辑区能力网关拒绝。
账号充值钱包属于账号付费余额，可由永恒与幻境人物共同用于会员、商城等正常
消费；幻境内获得的实体玉石和战利品仍归当前人物，不会复制给其他人物。

S1 不开放家园。统一命令分发会拒绝全部 `home_*` 入口，地图移动守卫也会拒绝
家园房间路径，因此旧书签不能绕过。幻境结束后人物回归永恒服，才恢复普通家园
购买和使用；系统不复制或合并其他人物的家园、地块、功能房、摆摊和库存。

同一期幻境人物位于同一逻辑组，可以在同房间使用现有受限交易。装备自身的
账号绑定、不可交易等规则仍优先执行。

## 个人挑战层级不会分流玩家

基础境及其上七档挑战仅调整人物自己的 PVE 伤害承受/输出、符合条件的个人套装
掉落权重和挂机时长。它不是新区、逻辑区、房间实例或 Worker 路由条件。选择不同
层级的玩家仍在同一地图见面、聊天和组队，PVP 公式也不受个人层级影响。

组队掉落按同房有效参战者中的最低层级计算，避免高层级人物替低层级人物绕过解锁
门槛。地图路由、`map_worker_rpc` 和集群启动脚本均不得读取个人挑战层级。

八档数据依次为：基础境 `100%/100%/100%/24h`，一至七境分别为
`95%/108%/112%/16h`、`90%/118%/125%/14h`、`85%/130%/140%/12h`、
`80%/145%/160%/10h`、`75%/162%/185%/8h`、`70%/182%/215%/6h`、
`65%/205%/250%/4h`；四项依次表示个人 PVE 输出、承伤、套装掉落权重和挂机上限。
永恒服按原有等级/战斗进度解锁；S1 每一档都必须在当前已解锁的最高难度亲自完成
9 个新章回。系统记录真实任务击杀发生时的最低难度，不能先用低难度打完、领奖前
临时切高来伪造精通。旧档若没有逐章难度证据，只补认基础档最多 9 章，因此最多
兼容解锁一次问道，不会连续补开高档。两个世界各自保存选择和进度，不能借另一世界的等级或章回跨越门槛。

## 六阶套装单件强度基线

套装的单件白板攻防在同等级、同底版下先提升到普通装备的 200%，再应用六阶品质
系数：新月 2.00 倍、曜星 2.10 倍、天穹 2.20 倍、太虚 2.32 倍、太初 2.46 倍、
寰极 2.64 倍。每件装备自带的职业契合属性同步提高一倍。随机词缀、锻造/洗炼值与
2/4/6/8/10 件分阶奖励不经过该倍率，防止多重乘算失控；旧装备和已保存套装无需
迁移即可按新读取规则生效。

## 生命周期管理

管理入口：`game_deal -> 幻境区生命周期管理`。

阶段只能依次前进：

1. `draft`（筹备中）
2. `registration`（资格开放）
3. `active`（进行中）
4. `settling`（回归结算）
5. `closed`（已关闭）

人工开放登记、正式开启、关闭本期和建立下一期草稿，都必须先预览，再点击
带 SHA-256 确认码的最终确认。S1 不设置自动结束日期，`active` 会一直持续；只有
管理员显式关闭后才执行 `active -> settling -> closed`。共享运行状态位于
`data_xiand/illusion_realm/runtime.json`，通过跨进程目录锁、修订号、临时文件、
备份和原子替换保存，禁止运行时手工编辑。

当前 S1 生命周期、关键事件和路线配置位于 `gamelib/etc/illusion_realm.json`，
九卷故事正文位于 `gamelib/etc/illusion_s1_story.json`，分镜图集位于
`images/illusion_s1/story/`。三个部分任一缺失或不一致都会让功能安全关闭。修改后
必须完整重启，让协调进程与全部 Worker 读取同一版本。

守护进程会把每一期已验收的配置与故事合并为按永久编号保存的内容快照，保存到
`data_xiand/illusion_realm/content/<ID>.json`，并按内容 SHA-256 追加不可变快照到
`data_xiand/illusion_realm/content/revisions/<ID>/<digest>.json`。根目录文件保持
运行时兼容，修订快照用于审计、复现和安全回滚，已存在的同摘要文件绝不覆盖。
换期预览与确认都会再次校验旧周期根内容快照；旧内容缺失时必须先恢复归档，
不能建立新周期，以保证尚未登录的旧人物仍按原期规则回归。
本期关闭后，回归永恒服的人物仍可
从“永恒回响”进入该期地图、阅读 81 章故事并查看冻结排行榜；奖励领取继续沿用
人物原来的幂等状态，不能重置、复制或重新刷取。进行中的下一期不会用新编号覆盖上一期
内容，永恒人物也不能提前进入仍处于 active 的幻境地图。

S1 主线固定为九卷八十一章，不设置自然日等待门槛。二十五个关键事件
必须同时配置真实房间或首领路径、中文地点名和所属章节；人物界面显示当前值/目标值
及地点提示，并提供只到“当前未完成目标”的安全直达；挂机、战斗、未来章节和跨世界
请求都会拒绝直达。章节只能顺序领取，未来章节事件在前一章未完成前必须失败关闭。
81 张章节图由 Vue、旧 JSP 明暗主题和旧 HTML5 共用。

S1 的六类普通猎物与九名卷主共用服务端复核的战斗预警框架，但拥有十五套
不同机制。普通猎物只在较长战斗中低频触发，失误造成的生命或仙力影响保持
在轻量范围且不能完成最后一击；卷主机制更频繁、更鲜明。预警应对始终校验
真实同房、当前敌人、S1 身份、时限和随机 nonce，不能用旧链接重放，也不会
越界改变永恒服、PVP、快速战斗或人物核心技能公式。

若共享运行状态不存在，程序只允许初始化 `S1` 草稿。后续期数必须从完整的已关闭
状态执行换期；删除运行状态文件不能作为跳期方式。换期还会先扫描账号索引，存在
损坏索引时自动拒绝。

## 开启 S1

1. 确认配置编号为 `S1`、`manual_close_only=1`、`duration_days=0`，入口和回归房间存在。
2. 完整构建并重启。
3. 在管理入口预览并开放资格登记。
4. 观察免费资格激活与账号索引日志；确认创建第一个人物前也必须购买 100 碎玉
   栏位，500 碎玉恰好增加 5 个栏位。
5. 预览并正式开启 S1；系统保持 active，直到管理员显式关闭。
6. 从真实账号中心确认 S1 选项仅在“有永久资格且阶段 active”时可选。

## 结束与下一期

1. 管理员在生命周期页点击“关闭本期并开始安全结算”，再次确认后立即进入
   `settling`。本 Worker 立即扫描在线人物，其他 Worker 最迟在 10 秒心跳内加入；
   系统保留 30 秒幂等结算窗口后原子关闭本期，不依赖重启。
2. 在线人物先保存回归位置和装备收据，再原子切换账号索引并回到永恒主城。
   某次保存失败会保留原世界身份并自动重试，不能带病切换。
3. 离线人物无需批处理；其下次真实登录会在共享仓库和钱包恢复之前完成同一结算，
   然后直接进入永恒服。
4. `closed` 不会自动开启或复刻下一期。所有服务器继续以现有永久服规则运行；
   已关闭内容以“永恒回响”开放，等待新人物、新任务、新装备开发和验收完成。
5. 新增下一期地图/NPC并把配置换成新的永久编号，例如 `S2`。
6. 完整重启；在管理入口预览“建立下一期草稿”，核对旧、新编号及人数后确认。
7. 旧状态自动归档到 `data_xiand/illusion_realm/history/`。尚未上线的旧人物保留
   唯一原档案，下次登录依据 `closed_ids` 自动回归，不会误入新一期。

## 部署验收

```bash
node vue_source/tests/account-characters.test.js
./scripts/build/build_vue_frontend.sh
./restart-local-workers.sh --workers 3
./scripts/map_worker_cluster.sh status
curl -fsS http://127.0.0.1:8888/health
```

必须同时满足：完整 TestUnit 零失败、3 个 Worker active、真实 Vue 首屏渲染通过、
账号登录 API 返回正确幻境状态、旧 JSP/TXD/书签与默认永恒人物创建不变、运行日志
无新增编译/存档/事务/路由异常。还必须验证 S1 的七个亲和组均进入静态目录，
公共营地映射稳定、不同野外章节可落到不同 Worker、跨章节移动完成后人物档案仍
只有一份，传统副本继续按队伍/实例键汇聚。十二职业必须分别从空档真实创建，完成
81 章与 25 个事件，且所有章节必须在同一活跃日、不注入未来日期的条件下通过；
每个职业都要用 1 级空档实际打赢第一只 S1 怪物，
依靠章节结算从 1 级自然成长至 69 级，获得并穿上十件套，存档重载后再以同一档案
回归永恒服。禁止测试直接写等级或只伪造计数来替代这两项验收。
此外必须运行任务导航回归：传送成功后，狩猎目标必须出现定量挂机按钮，首领目标
必须出现直接挑战按钮，失败路径不得伪造成功动作；八档难度要覆盖十二职业、永恒/S1
隔离、普通/快速战斗、PVP 不变、掉落单调性与 Worker 路由无关。神秘商店动态装备
必须由服务器签名报价固定扣除 10 碎玉，伪造客户端价格、重复报价或存档失败均不能
少扣、多发或复制装备。
