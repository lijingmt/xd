# 仙道幻境区：新月幻境·S1

## 定位

`S1` 是首期永久编号，玩家界面显示“新月幻境·S1”。一期持续 90 天。
玩家按注册账号购买一次永久资格，今后每一期均可创建一名新的幻境人物；没有
资格也不影响永恒服和旧登录方式。

S1 当前永久资格价格为 500 碎玉，价格保存在配置中，开放登记前可以调整；正式
开启后不建议在本期中途改价。

幻境人物始终使用一份普通人物 `.o` 档案。期满回归只改变账号人物索引中的
世界状态，不复制人物、背包、装备或仓库数据。

## S1 内容

- 11 个静态房间始终属于同一个地图 Worker 一致性域。
- 七章历程按顺序开放，共发放本职业 10 件新月底版套装。
- 第三章前选择一条本期不可更改的路线：
  - 寻星：寻找水镜月印、隐月星核、归真月印；
  - 破阵：分别击败断桥镇星使、月庭巡将、归真月主；
  - 同心：完成配置要求的同队击杀。
- 章节奖励逐人物领取、账号绑定、重复请求幂等。领取落盘失败会同时撤销装备
  和领取状态。

## 世界隔离

进行中的幻境人物不能接入永恒服的账号共享仓库、共享充值余额、共享宠物和
拍卖行。跨世界的可见、战斗、组队、聊天、邮件、赠送和交易继续由逻辑区能力
网关拒绝。

同一期幻境人物位于同一逻辑组，可以在同房间使用现有受限交易。装备自身的
账号绑定、不可交易等规则仍优先执行。

## 生命周期管理

管理入口：`game_deal -> 幻境区生命周期管理`。

阶段只能依次前进：

1. `draft`（筹备中）
2. `registration`（资格开放）
3. `active`（进行中）
4. `settling`（回归结算）
5. `closed`（已关闭）

每次切换都必须先预览，再点击带 SHA-256 确认码的最终确认。共享运行状态位于
`data_xiand/illusion_realm/runtime.json`，通过跨进程目录锁、修订号、临时文件、
备份和原子替换保存，禁止运行时手工编辑。

当前 S1 内容配置位于 `gamelib/etc/illusion_realm.json`。修改配置后必须完整重启，
让协调进程与全部 Worker 读取同一版本。

若共享运行状态不存在，程序只允许初始化 `S1` 草稿。后续期数必须从完整的已关闭
状态执行换期；删除运行状态文件不能作为跳期方式。换期还会先扫描账号索引，存在
损坏索引时自动拒绝。

## 开启 S1

1. 确认配置编号为 `S1`、周期为 90 天，入口和回归房间存在。
2. 完整构建并重启。
3. 在管理入口预览并开放资格登记。
4. 观察购买与账号索引日志。
5. 预览并正式开启 S1；系统从确认时刻计算 90 天结束时间。
6. 从真实账号中心确认 S1 选项仅在“有永久资格且阶段 active”时可选。

## 结束与下一期

1. 自然到期或管理员提前进入 `settling`。
2. 玩家登录或点击安全回归时，先保存回归位置和装备收据，再原子切换账号索引。
3. 确认回归日志、人物数量和索引异常数后关闭本期。
4. 新增下一期地图/NPC并把配置换成新的永久编号，例如 `S2`。
5. 完整重启；在管理入口预览“建立下一期草稿”，核对旧、新编号及人数后确认。
6. 旧状态自动归档到 `data_xiand/illusion_realm/history/`。尚未上线的旧人物保留
   唯一原档案，下次登录依据 `closed_ids` 自动回归，不会误入新一期。

## 部署验收

```bash
node vue_source/tests/account-characters.test.js
./scripts/build/build_vue_frontend.sh
./restart-local-workers.sh --workers 3
./scripts/map_worker_cluster.sh status
curl -fsS http://127.0.0.1:8888/health
```

必须同时满足：完整 TestUnit 零失败、3 个 Worker active、真实 Vue 首屏渲染通过、
账号登录 API 返回正确幻境状态、旧 JSP/TXD/书签与默认永恒人物创建不变、运行日志
无新增编译/存档/事务/路由异常。
