# 仙道新月幻境 S1：内容纵深与单月节奏

本轮在保留八十一章主线、十二职业、八档个人难度和原有战斗公式的前提下，为 S1 增加三层可选内容。所有数据仍保存在人物唯一 `.o` 档案的 `newmoon_journey` 子树中，不创建第二套人物存储。

## 新增玩法

- 月下偶遇：主线真实战斗会在确定的安全间隔后触发一场三杀小事件；共十二场。事件不挡主线，不收费，只认配置中的真实 NPC 与真实房间。
- 月蚀回廊：完成八十一章后开放。每周从三条路径中轮换一条，依次挑战三名故事首领；每周只能结算一次。
- 同心筑月：月下偶遇与月蚀回廊贡献全服共同叙事进度。总数来自现有跨 Worker 排行快照，快照不完整时拒绝显示猜测数字。
- 旅途共鸣：月忆兽、九卷秘术/记忆与同职业十件新月套装形成三档非战斗共鸣，只改变称谓、叙事和共同目标贡献，不进入伤害、PVP、掉率或个人难度公式。

## 单月掉落曲线

九个卷末剧情道具改为在卷末首领战前准备，掉率（万分比）为 `2000/1500/1000/800/600/500/400/300/200`，对应硬保底为 `5/7/10/13/17/20/25/34/50` 次。终章为 `2%`、最坏 50 次，玩家完成信物后再进入剧情高潮，不会击败月主后被迫回普通猎场刷数百或数千只怪。

支线确定性凭证仍可在完成本卷真实四幕战斗和卷末权威剧情后替代随机实体，因此概率道具提供长期收集感，不会把主线永久锁死。

## Worker 与存档边界

- 房间和 NPC 归属仍由现有一致性 Worker 路由决定；新玩法不参与房间哈希。
- 人物状态先复制、加锁、保存，失败完整回滚；成功后才发布派生快照。
- 全服共同目标没有各 Worker 独立计数器，避免切图、重启或扩容后重复累计。
- S1 关闭后不再刷新偶遇或周常；人物结算和永恒回响流程保持原样。

## 玩家入口

`新月支线` 页面增加“月下偶遇、月蚀回廊、同心筑月、旅途共鸣”入口。每个可战斗目标均提供一键前往与从当前房间真实 NPC 列表生成的挑战按钮；目标刚被其他玩家击败时只提示等待刷新，不会误杀同名或错误对象。
