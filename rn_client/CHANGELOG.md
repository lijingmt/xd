# 仙道原生客户端 更新日志

## v0.2.0 (2026-08-29)

### 重大突破
- **iOS 原生构建成功**：Expo prebuild → CocoaPods → Xcode 编译 597 模块 → iPhone 模拟器安装启动

### 新增功能
- 多角色账号中心：登录→角色仪表盘→选角进游
- 客户端内建角：种族→职业（隐藏门禁）→性别→名字→头像
- 会话保持：AsyncStorage 持久化，重开免登录
- 底部六 Tab：场景/状态/物品/技能/装备/更多(14个常用功能)
- 装备面板：14 槽位结构化卡片，稀有度染色，一键穿卸
- 战斗场景：左右对峙布局，Animated 血条平滑过渡
- 浮动战斗数字：伤害(暴击金色)/治疗/闪避/格挡/中毒/胜利
- 技能施法动画：24 种类型(剑气/火/冰/雷/太古/神太古等)
- 战斗统计条：实时 DPS/总输出/承受/暴击/击杀
- Buff 药丸：header 显示生效中的丹药/特药
- 离线检测：连续3次失败显示红色横幅，恢复后自动消失
- 下拉刷新：手动拉最新画面

### 稳定性
- Error Boundary：渲染崩溃显示恢复界面而非白屏
- 网络超时：15 秒 AbortController
- 401 智能恢复：先重选角色，账号令牌也失效才登出
- 遗留 HTML 渲染：div/font/br 标签正确解析
- 图片走 Tomcat 8080 端口，失败显示占位方块
- 垃圾行过滤：纯数字单字符行自动丢弃
- React.memo + 内容哈希 key：全量替换时只渲染变化行
- FlatList 虚拟化调优：windowSize 8 / removeClippedSubviews
- 智能滚动：只在底部附近才跟随新行
- 定时器统一清理：防 unmount 后 setState

### 挂机系统
- flushview 轮询（txpike9 同款）：战斗 1s / 待机 3s 自适应
- AppState 恢复：iOS 切后台回前台立即补一帧
- 乐观反馈：点挂机按钮立即变色+转圈

### 测试
- 59 项离线单元测试（node 零依赖）
- 14 步在线冒烟（注册→建角→战斗→挂机→装备全链路）
- 共 73 项，全部通过
